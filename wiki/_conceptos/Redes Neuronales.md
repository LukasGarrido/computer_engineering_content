# Redes Neuronales

> Modelos computacionales inspirados en las neuronas biológicas, compuestos por capas de nodos interconectados. Son la base del Deep Learning y permiten aprender representaciones complejas de datos.

## Aparece en

### Ciencia de Datos
- [[08_Introduccion_Machine_Learning|Fundamentos de Machine Learning]] — redes neuronales como parte del ecosistema ML
- [[10_Series_de_Tiempo_y_Procesamiento_Imagenes|Series de Tiempo y Procesamiento de Imágenes]] — redes convolucionales para imágenes

## Notas
- Las redes neuronales se construyen sobre conceptos de [[Regresion Lineal|regresión]] (el perceptrón es una regresión lineal con función de activación).
- Se evalúan con las mismas [[Metricas de Evaluacion|métricas]] que otros modelos de [[Machine Learning]].
