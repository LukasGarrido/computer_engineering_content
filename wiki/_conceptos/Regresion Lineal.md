# Regresión Lineal

> Modelo estadístico que describe la relación entre una variable dependiente y una o más variables independientes mediante una función lineal. Su variante logística extiende el concepto a problemas de clasificación binaria.

## Notas
- La regresión lineal es el modelo base sobre el que se construyen modelos más complejos como [[Machine Learning|modelos de ML]].
- Las [[Metricas de Evaluacion|métricas de evaluación]] para regresión incluyen MSE, RMSE y R².
